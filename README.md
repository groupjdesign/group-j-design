# Group J Design

A simple one-page website for Group J Design.

## Site files

- `index.html` — The website page
- `group-j-logo.svg` — Group J Design logo used on the page
- `README.md` — Notes and maintenance instructions

## Updating the website

To change the website:

1. Open `index.html` in a plain-text editor.
2. Make the needed edits.
3. Save the file.
4. Upload or commit the updated file to this GitHub repository.
5. GitHub Pages will publish the update automatically, usually within a few minutes.
